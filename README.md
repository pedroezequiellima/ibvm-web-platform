# 🏛️ Igreja Batista Vila Marcela (IBVM) - Web Portal

Plataforma web oficial da Igreja Batista Vila Marcela, desenvolvida para conectar a comunidade, centralizar informações dos ministérios e facilitar o engajamento em campanhas e ações sociais.

## 🚀 Tecnologias Utilizadas

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Ícones:** [Lucide React](https://lucide.dev/) / React Icons
* **Linguagem:** TypeScript / JavaScript

## ✨ Funcionalidades Principais

* **Roteamento Dinâmico:** Páginas de ministérios geradas dinamicamente via slugs (`/igreja/ministerios/[slug]`).
* **Navbar Inteligente:** Efeitos de scroll adaptáveis (transparente na Home, sólido nas páginas internas).
* **UI/UX Moderna:** Design focado em tons de terra (Earth Tones), com efeitos de Glassmorphism e transições suaves.
* **Integração Social:** Seções conectadas diretamente aos perfis do Instagram dos ministérios.
* **Mobile-First:** Layout 100% responsivo para todos os dispositivos.
